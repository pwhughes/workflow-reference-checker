# Optomatic browser-local release checks

This public catalog is a practical index for teams who want a narrow, browser-local preflight check without uploading their working text or exports. Each product has a free check and a one-time paid downloadable record after Stripe Checkout—no subscription or account.

## API and release work

- [Webhook Contract Checker](https://webhook-contract-checker.optomatic.app) — structural JSON webhook changes.
- [OpenAPI Change Checker](https://openapi-change-checker.optomatic.app) — removed paths and methods.
- [Environment Manifest Diff](https://environment-manifest-diff.optomatic.app) — missing or unexpected variable names.
- [Docker Tag Checker](https://docker-tag-checker.optomatic.app) — mutable Docker image references.
- [Dependency Range Checker](https://dependency-range-checker.optomatic.app) — broad JavaScript dependency ranges.
- [Cron Schedule Checker](https://cron-schedule-checker.optomatic.app) — malformed or overly frequent schedules.
- [Workflow Reference Checker](https://workflow-reference-checker.optomatic.app) — mutable external Actions references.

## Content and web QA

- [Translation Token Checker](https://translation-token-checker.optomatic.app) — missing placeholders in localized copy.
- [UTM Link Checker](https://utm-link-checker.optomatic.app) — campaign-link conventions.
- [Embed Inventory Checker](https://embed-inventory-checker.optomatic.app) — third-party scripts and iframes.
- [Redirect Map Checker](https://redirect-map-checker.optomatic.app) — duplicate sources and redirect loops.
- [Robots Rules Checker](https://robots-rules-checker.optomatic.app) — basic robots.txt review.
- [CSP Policy Checker](https://csp-policy-checker.optomatic.app) — broad policy allowances.
- [Form Field Checker](https://form-field-checker.optomatic.app) — controls missing detectable labels.
- [JSON-LD Field Checker](https://jsonld-field-checker.optomatic.app) — basic structured-data fields.
- [Markdown Link Checker](https://markdown-link-checker.optomatic.app) — empty and insecure links.

## Operations exports

- [SLA Export Auditor](https://sla-export-auditor.optomatic.app) — unresolved overdue tickets.
- [CSV Duplicate Auditor](https://csv-duplicate-auditor.optomatic.app) — duplicate rows and blanks.
- [Log Secret Scrubber](https://log-secret-scrubber.optomatic.app) — common credential-shaped strings.
- [Invoice Sequence Checker](https://invoice-sequence-checker.optomatic.app) — duplicate and missing invoice IDs.

All diagnostics run in the browser and have their own public privacy/contact page. Choose the narrow checker that matches the job; do not treat these as professional, legal, or compliance advice.
